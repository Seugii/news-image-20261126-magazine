## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is standard-library-only: it validates `entry.png` (PNG signature, IHDR size 1024x1024, 1 MiB limit) and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifying the copy's hash matches the source.
